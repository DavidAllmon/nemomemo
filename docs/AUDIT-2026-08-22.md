# Deep-dive audit — 2026-08-22

Full-application audit: three parallel code reviews (server correctness, frontend
correctness, simplification) plus a hands-on functional pass of every feature against a
fresh instance. **All correctness findings below were fixed in the same change** and have
regression tests (`server/src/test/security.test.ts`); the simplification items are a
backlog, deliberately not yet applied.

## Correctness findings — all FIXED ✅

| # | Severity | Finding | Fix |
| --- | --- | --- | --- |
| 1 | **Critical** | Relation stubs (`referencing`/`referencedBy`) bypassed the ACL: any signed-in user could link any memo UID to their own memo and read a live snippet of its content — including private, archived, and expired memos. | `setReferenceRelations` now refuses targets the actor can't read; `buildMemoDtos` filters every stub through a new `canGlimpseMemo` visibility check per viewer. |
| 2 | High | `@mentioning` someone in a **PRIVATE** memo delivered them an inbox notification with a content snippet they had no right to see; snippets also survived a memo later being made private. | Mentions in private memos notify nobody; the inbox re-checks visibility at read time and nulls the snippet/link when access is gone. |
| 3 | High | First-user-becomes-admin had a check-then-insert race across the `await bcrypt.hash` yield — two concurrent signups could both become admin. | Hash moved before the check; the count + insert now run in one synchronous SQLite section with no interleaving window. |
| 4 | Medium | Dory expiry wasn't enforced on every read path: the comment list ignored `forget_at`, comments could themselves be made Dory, and a comment outlived its expired parent until the sweeper tick. | Expiry check added to `checkMemoRead` itself (memo *and* effective parent — even share tokens can't resurrect), the comment list query gained the guard, and Dory on comments is rejected. |
| 5 | Medium | Unknown `/api/*`/`/file/*` paths fell through to the SPA's HTML with a 200 in production. | Explicit JSON 404 catch-alls after the API routes. |
| 6 | High (FE) | The share page's query cache (`['shares', token]`) was never invalidated by any mutation — edits, checkbox ticks, and reactions appeared to silently revert there. | All memo mutations now invalidate the `shares` cache. |
| 7 | Medium (FE) | Deleting a memo from its share page left a fully-rendered ghost. | Post-delete navigation covers `/memos/*` including share routes. |
| 8 | High (FE) | A search term containing `\` corrupted the filter expression; a trailing `\` broke the entire feed with a parse error until the chip was removed. | Backslashes escaped before quotes in `chipsToExpression`; tag chips strip both. |
| 9 | Medium (FE) | Posting a comment didn't refresh feed comment counts. | Comment mutation invalidates list queries. |
| 10 | Low (FE) | `?redirect=` after sign-in accepted absolute URLs (crashed on cross-origin push). | Only same-origin relative paths are followed. |
| 11 | Low (UI) | Members settings showed an Archive button on your own row (server would reject it). | Hidden for self. |

## Verified in good shape

Central read-ACL as one pure function (API + file server), the filter parser→SQL
compiler (parameterized, LIKE-escaped — verified against `%`/quote/backslash inputs),
batch DTO assembly (no N+1), tag rename incl. nested descendants and payload rebuild,
session lifecycle & SameSite CSRF posture, XSS surface (no raw HTML, sanitized hrefs),
task-checkbox source-splicing, dory sweeper transactionality, TanStack query-key
hashing, DST-safe calendar math.

## Simplification backlog (documented, not yet applied)

Ranked by value/effort:

1. **S/high** — Tag & mention regexes duplicated in `shared/src/markdown/extract.ts` and
   `web/src/components/memo/MemoContent.tsx`; export from shared, import in web.
2. **M/high** — `GET /users/-/tags` and `/users/:u/stats` load up to 10k rows and
   aggregate in JS; move to SQL `json_each(...) GROUP BY` (the technique already exists
   in `filter-sql.ts`). Removes the silent 10k cap.
3. **S/med** — Owner-check (`creatorId !== viewer.id && role !== 'ADMIN'`) copied in
   three route files; extract `assertOwner` into `services/acl.ts`.
4. **M/high** — No route-level code splitting: all pages + CodeMirror + highlight.js in
   one 1.4MB chunk. `React.lazy` per route; biggest wins are Settings/Views/Attachments
   and the editor/highlighter chunks.
5. **S/low** — `server/package.json` declares four remark/unified deps it never imports
   (they belong to shared); remove.
6. **S/low** — `toggleTask` (index-based) in shared is dead code superseded by
   `toggleTaskAt`; delete it and its test.
7. **S/low** — Logo SVG duplicated between `web` and `site`; add a "canonical copy"
   comment or wait for a shared UI package.

Also noted during the audit (small polish items): comments can technically be archived
via PATCH (harmless — they just vanish from the thread), and the demo's stats endpoints
would benefit from item 2 before any instance grows past a few thousand memos.
