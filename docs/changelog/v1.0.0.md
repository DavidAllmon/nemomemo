## What's new
- **NemoMemo Cloud is open!** Don't want to run your own server? We'll host a private
  reef for you at your-name.trynemomemo.com — $1.99/month or $19/year, ready about a
  minute after checkout. The live demo is the try-before-you-buy.
- **Billing that stays out of your way.** Reefkeepers get a Billing tab in Settings with
  their subscription status and a secure Stripe portal for card changes and cancellation
  — we never see your card.
- **Self-hosting stays free, forever.** Run NemoMemo yourself at no cost, with the full
  source code. The only thing reserved is reselling it as a hosted service — that's how
  the lights stay on.
- **A version number that means something.** The About page now shows exactly which
  NemoMemo you're on, with a link to this very changelog.

## Technical notes
- Cloud multi-tenancy (`server/src/cloud/`): registry DB + one SQLite database and
  uploads dir per reef under `data/reefs/<slug>/`, resolved by Host header via wildcard
  DNS + Cloudflare Tunnel, LRU handle cache, all behind `NEMOMEMO_CLOUD=1` (self-host
  path byte-identical; cross-tenant isolation test matrix).
- Stripe billing: checkout (month/year prices), signed webhooks scoped to NemoMemo on a
  shared Stripe account (session `app` metadata + subscription-id matching), pay-first
  claim flow (hashed single-use tokens, recoverable via Stripe customer metadata),
  lifecycle states provisioned → active → past_due → suspended, billing portal API on
  reef hosts.
- Fair-use brakes for hosted reefs (`Config.cloudLimits`, null = self-host unlimited):
  member cap at signup, storage cap at upload; cloud defaults 25 members / 5 GB.
- Web: Settings Billing section, past-due banner, cloud UI renders only when the cloud
  API answers.
- Relicensed MIT → Elastic License 2.0; all "open source / MIT" copy replaced with
  "free to self-host, source-available".
- Versioning system introduced: canonical version in root `package.json` mirrored to
  `NEMOMEMO_VERSION` in shared, `pnpm release` (bump + changelog gate + `release:` commit
  + annotated `vX.Y.Z` tag), pre-push guard, public changelog page on the marketing site.
