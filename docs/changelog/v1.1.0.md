## What's new
- **Back up your reef with one click.** Reefkeepers now have a Backups section in
  Settings — press one button and download your entire reef (every memo, every photo
  and file) as a single zip you can keep somewhere safe.
- **A proper backup guide for self-hosters.** The deploy docs now walk through the
  whole thing in plain steps: safe snapshots, making them automatic every night, free
  places to store them off your machine, and exactly how to restore.

## Technical notes
- `GET /api/v1/instance/backup` (admin-only): consistent SQLite snapshot via
  better-sqlite3's online backup API + the uploads dir, streamed as a zip
  (archiver v7 — v8 rewrote its API; loaded via createRequire for CJS interop under
  vitest). Zip layout mirrors the data dir for unzip-and-replace restore.
- Web: Settings → Backups section (admin-only), plain download via cookie-authed
  navigation.
- Docs (`site/content/docs/deploy.mdx`): safe-snapshot Docker commands, cron recipe,
  restic off-machine section with R2/B2 free-bucket + token walkthroughs, restore steps.
