## What's new
- **Napping reefs can wake themselves up.** If a cloud reef's subscription
  lapses, its page now has a "Wake it up" button — fix the payment and
  everything is exactly as you left it. No support emails required.
- **The 90-day promise is now automatic.** Suspended reefs are kept for 90 days
  and then deleted for good, exactly as our terms say — previously that cleanup
  was a manual chore.
- **"What's new" finds you.** After an update, a one-line banner points to the
  changelog — dismiss it and it stays gone until the next release.
- **Sign-in niceties**: an eye button to peek at your password, and a heads-up
  when Caps Lock is on.

## Technical notes
- `/cloud/rescue?reef=<slug>` (rate-limited): checkout session created with the
  reef's existing `customer`; `ensureProvisioned` now updates a changed
  subscription id and flips suspended/past_due → active (never touches
  provisioned/canceled). Suspended HTML pages render a wake-up CTA; API/file
  callers get JSON with `rescueUrl`.
- Registry migration `0002_status_changed_ts` (own chain, additive);
  `setReefStatus*` stamps it; `listSuspendedBefore(cutoff)` +
  `cloud/reef-sweeper.ts` (`REEF_GRACE_SECONDS` = 90d) run at boot + daily.
  Deletion = fleet evict + `rm -rf` reef dir + status canceled, logged.
- Web: `WhatsNewBanner` (localStorage `nemo-last-seen-version`, silent first
  visit), password visibility toggle + Caps Lock hint on the auth page.
- Public docs: cloud page documents the lapse→nap→wake lifecycle and the
  90-day deletion. Suite: 111 server / 27 web / 27 shared.
