## What's new
- **Export your memos as plain Markdown.** Settings → Account has a new "Export as
  Markdown" button: one zip with a readable `.md` file for every memo you've written —
  dates, tags, and visibility noted at the top of each file — plus all your attachments,
  linked so everything opens correctly in any notes app. Your words are never locked in
  this tank. 🐚

## Technical notes
- New `GET /api/v1/memos/export/markdown` (any signed-in user, own memos only): zip of
  `memos/YYYY-MM-DD-<uid>.md` files with YAML frontmatter (created/updated, visibility,
  pinned/archived, Dory `forgets`, tags from the payload, attachment paths); comments
  export under `comments/` with `comment_on: <parent-uid>`. Attachment files ride along
  under `attachments/<uid>/<filename>` and inline `/file/attachments/…` links are
  rewritten to those relative paths.
- Export assembly lives in `server/src/services/export-service.ts`; every row passes
  through `checkMemoRead`, so expired Dory memos can never leak into an export.
- Docs: Markdown-export sections added to deploy.mdx (Backups) and cloud.mdx.
