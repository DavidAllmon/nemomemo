## What's new
- **Save any memo as a Markdown file.** Every memo's ⋯ → Copy menu now has
  "Download as .md" — one clean file with the memo's dates, visibility, and tags
  noted at the top, ready for any notes app. The everything-at-once export moved
  out of Settings; it lives on as a simple URL for power users (see the docs). 🐚

## Technical notes
- New `GET /api/v1/memos/:uid/markdown`: single-memo download, gated by the same
  `checkMemoRead` path as reading the memo (readable = savable). Shares the
  frontmatter renderer with the bulk export via `renderMemoMarkdown` /
  `markdownFilename` in `export-service.ts`.
- The Settings → Account "Export your memos" card is removed; the bulk
  `GET /api/v1/memos/export/markdown` endpoint is unchanged and now documented in
  deploy.mdx as a power-user URL. Backups-tab copy and cloud.mdx repointed to the
  per-memo menu.
