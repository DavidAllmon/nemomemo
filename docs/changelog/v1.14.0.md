## What's new
- **Deep Sea got deeper.** The dark theme now matches the look of our website: darker water, crisper edges, and the same clownfish orange and Dory blue everywhere. Your theme setting is untouched — if you were using Deep Sea, it simply looks better now.
- **A real fish in your browser tab.** The app now shows the NemoMemo clownfish as its tab icon instead of a generic emoji.

## Technical notes
- `web/src/index.css`: the `deep-sea` theme (and the matching `prefers-color-scheme: dark` fallback block) reskinned to the marketing site's Terminal Reef palette — background `oklch(0.15 0.028 256)`, hairline borders `oklch(0.28 0.035 252)`, sidebar near-black, plus a theme-scoped `--radius: 0.375rem` (the derived `--radius-sm/md` calc values clamp to ~0 per CSS spec, which is intended). The `data-theme='deep-sea'` identifier and the Shallows light theme are unchanged, so stored preferences migrate cleanly.
- `web/index.html`: emoji data-URI favicon replaced with `web/public/favicon.svg` (the same mark as the marketing site's icon) and `theme-color` metas added for both color schemes.
