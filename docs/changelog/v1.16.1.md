## What's new
- **The reef loads faster.** The app now fetches only what each page needs, so first load is about a third of what it used to download — the editor and code-coloring pieces arrive quietly in the background right when you need them.

## Technical notes
- Route-level code splitting (audit #4): all pages in `App.tsx` are `React.lazy` with a `Suspense` fallback; the initial JS entry drops from a single 1.43MB chunk to 463KB (146KB gzip).
- The TipTap/ProseMirror chain (481KB) is isolated behind `components/editor/lazy.tsx` (`LazyMemoEditor`/`LazyCommentEditor`) — call sites import from there, never from the editor modules directly.
- `MemoContent` dynamic-imports `rehype-highlight` (highlight.js) only when a memo actually contains a fenced code block; content renders immediately and re-renders highlighted once the chunk lands.
- No behavior changes; markdown-bridge fidelity suite and full workspace tests green.
