## What's new
- **Every to-do, one page.** The new **Open tasks** page (in the sidebar under Views) gathers every unchecked checkbox from all your memos in one place — and you can tick them off right there. Each group links back to its memo.
- **Snappier profiles and tag lists.** Tag counts and profile stats are now computed by the database itself, so they stay instant no matter how big your reef grows.

## Technical notes
- `extractProps` now counts unchecked tasks (`property.incompleteTasks`); payload composition moved to shared as `buildMemoPayload` (single source for write paths and backfills). `MemoPropertyDto.incompleteTasks` and `UserStatsDto.openTaskCount` added (additive).
- Payload backfill runs at boot inside `createDb` (payload is JS-derived JSON, so a .sql migration can't rewrite it): rows missing `$.property.incompleteTasks` are rewritten in one transaction without touching content — FTS triggers stay quiet. Cloud reefs heal on first open.
- `/-/tags` and `/:username/stats` now aggregate in SQL (`json_each`/`json_extract`) through the new `buildMemoListWhere` — the single WHERE builder both listings and aggregations share, so Dory/bottle/comment guards are inherited by construction. The 10k-memo stats cap is gone (audit #2).
- New lazy route `/tasks` (2.5KB chunk); the sidebar "Open tasks" entry now links there instead of filtering the home feed. Toggling splices the markdown source via `toggleTaskAt` — never re-serializes.
- Dead `toggleTask` removed from shared (audit #6); `toggleTaskAt` gained direct test coverage.
