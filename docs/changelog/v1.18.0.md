## What's new
- **Find photos by tag.** The Attachments page can now filter by tag — pick any tag and see just the files from those memos. Great for pulling up every photo from a trip (`#trips/tidepools` finds them; so does just `#trips`).

## Technical notes
- `GET /api/v1/attachments?tag=` — owner-scoped SQL join over attachment→memo with `json_each` tag matching (implied ancestors included). Both time guards apply in the join: an expired Dory memo's or pending bottle's files never surface through the gallery (leak tests in `attachments-gallery.test.ts`).
- Attachments page: tag dropdown (fed by the existing `/-/tags` aggregate) alongside the type tabs; reef-voiced empty state for tag misses. `useAttachments` gains a `tag` param.
