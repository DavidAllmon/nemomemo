## What's new
- **Restoring a backup waits properly for the reef to come back.** The page now
  genuinely watches for the server to return before reloading, and if you run NemoMemo
  by hand without something that restarts it, it tells you plainly to start it again
  instead of leaving you guessing.

## Technical notes
- Post-restore poll switched from `/healthz` (not forwarded by the Vite dev proxy, so
  dev reloaded instantly against a dead API) to `/api/v1/instance/profile` with
  `cache: no-store`; initial 2.5s grace before polling; timeout message now covers the
  no-supervisor case (tsx/source runs without Docker's restart policy).
