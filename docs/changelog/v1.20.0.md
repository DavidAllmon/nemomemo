## What's new
- **Voice memos.** Tap the new microphone button in the editor to record a thought out loud — it attaches to your memo and plays back right in the feed with a proper player. Perfect for capturing ideas while walking.
- **Voice memos you can search.** If your reef has transcription set up (one setting, works with OpenAI or a free local Whisper server), every recording gets a written transcript under the player — and searching for something you *said* finds the memo, just like something you typed.

## Technical notes
- Web: `RecordButton` (MediaRecorder, `audio/webm` with `audio/mp4` Safari fallback) in the editor toolbar; `AttachmentPanel` renders `audio/*` attachments as inline `<audio controls preload="none">` players with a collapsible transcript block.
- Server: `services/transcribe.ts` — `transcribeEngine(url, key, model)` POSTs multipart to any OpenAI-compatible `/audio/transcriptions` endpoint; runs as a second `OcrQueue` on the same process-wide serialized lane, writing `attachment.extracted_text` → `attachment_fts` → search (all reusing the v1.19.0 OCR pipeline). Failures never fail an upload.
- `AttachmentDto.extractedText` added (OCR text or transcript) — additive; exposed only through memo-visibility-gated paths.
- Env: `NEMOMEMO_TRANSCRIBE_URL` / `NEMOMEMO_TRANSCRIBE_KEY` (optional) / `NEMOMEMO_TRANSCRIBE_MODEL` (default `whisper-1`); documented in deploy docs this release. Cloud can set fleet-wide via env — no cloud code paths touched.
