## What's new
- **Dictation has a sensible speed limit.** You can dictate as much as you like — the
  cap is far beyond what anyone talking into a microphone will reach — but a script
  hammering it now gets told to take a breath. Nothing changes for normal use.

## Technical notes
- `POST /api/v1/dictation/session` was auth-only with no rate limit, and minting an
  ephemeral Realtime key costs money downstream. On a public reef — the demo signs
  every visitor into one shared account — that was an unbounded faucet.
- Capped at `DICTATION_MAX_PER_WINDOW = 20` per 10 minutes, keyed **per IP**. Per member
  would be wrong for exactly the shared-account case: one abuser would mute every other
  visitor. 20/10min is one dictation every 30 seconds sustained.
- This bounds *minting*, not spend — audio streams from the browser straight to OpenAI —
  so `deploy.mdx` and `.env.example` both now say a budget on the API project is the
  real backstop.
- `makeRateLimiter` gained an optional `message`; its "Too many attempts" copy only ever
  fitted the auth paths. Existing callers are unchanged.
