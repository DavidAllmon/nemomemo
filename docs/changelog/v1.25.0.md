## What's new
- **Every edit is undoable now.** Each time you save a memo, the old words are kept.
  Open **⋯ → History** to see a memo's past versions, compare them line by line with
  what it says today, and bring one back with a single click. Restoring keeps the
  current version in the history too — nothing is ever lost by looking back.
- **Your history is private.** Only you can see your memo's past versions — even on a
  public memo, other people only ever see the latest words. NemoMemo keeps the last
  20 edits per memo, for 90 days.

## Technical notes
- New `memo_revision` table (migration 0009, FK cascade off `memo`); the PATCH content
  path writes the prior content inside the same transaction as the update.
- `GET /memos/:uid/history` and `POST /memos/:uid/history/:revisionId/restore` are
  creator-only AND gated by `checkMemoRead`, so trash, Dory expiry, and pending
  bottles can never leak old text. Restore recaptures the pre-restore content,
  rebuilds the payload, and bumps `updatedTs`; no mention notifications.
- Revision pruning (keep `REVISION_KEEP_COUNT` = 20 per memo, age out after
  `REVISION_RETENTION_SECONDS` = 90 days) runs as the sixth pass of the one
  scheduler tick.
- Web: hand-rolled LCS line diff (`web/src/lib/diff.ts`) renders the history dialog;
  history queries live under the `['memos']` key prefix so edits invalidate them.
