## What's new
- **Do it to many memos at once.** A new **Select** button above your feed (on Home
  and in the archive) lets you pick several memos and act on them together: archive
  or unarchive them, add a tag to all of them, or move them to the trash — up to 100
  at a time.
- **Still nothing is ever lost.** Bulk delete uses the same 7-day trash as deleting
  one memo, and bulk-tagging keeps each rewritten memo's old words in
  **⋯ → History**.

## Technical notes
- New `POST /api/v1/memos/bulk` (`{uids ≤ 100, action: archive|unarchive|trash|tag,
  tag?}` → `{affected}`): creator-only, one transaction, non-qualifying rows
  (not yours, trashed, Dory-expired, already in the target state) skipped silently.
- Semantics inherited from the single-memo paths: archive clears `forget_at`
  (Dory rescue); trash marks comments too and never extends an existing clock;
  tag-add appends `\n\n#tag` (safe after fences), skips memos whose extracted tags
  (implied ancestors included) already contain it, and calls `captureRevision()`
  per rewrite. Static route registered before `/:uid`.
- Web: selection mode lives in `MemoFeed` (`selectable` prop, Home + Archived);
  cards click-toggle via `onClickCapture`, sticky bottom action bar with tag and
  trash dialogs. `useBulkMemoAction()` invalidates the memo caches.
