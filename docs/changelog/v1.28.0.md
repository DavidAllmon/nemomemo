## What's new
- **Start from a template.** The compose box gained a **Template** button with four
  ready-made skeletons — daily journal, standup, meeting note, and recipe — and the
  date fills itself in.
- **Make your own.** Write a memo once, choose **Save current memo as template…**,
  and it becomes a one-tap starting point. Keep up to 20; they're yours alone.

## Technical notes
- Custom templates stored per member in `user_setting` under a new `MEMO_TEMPLATES`
  key (exact `memoViews` pattern — no migration); `memoTemplateSchema` (title ≤ 64,
  content ≤ CONTENT_LENGTH_LIMIT, max 20) rides `updateUserSettingsRequestSchema`,
  and `/users/-/settings` GET/PATCH round-trip them.
- Web: `lib/templates.ts` holds the built-ins and the `{date}` token (filled with
  the browser-local date at apply time); `TemplatesMenu` in the compose box (create
  mode only) applies into the editor via `setMarkdown` — appending under an existing
  draft rather than replacing it — and saves/deletes custom entries through
  `useUpdateUserSettings`.
