## What's new
- **Slash commands in the editor.** Type `/` at the start of a line and pick from a
  little menu: to-do list, bullet list, heading, code block, quote — and `/dory`,
  which flips the memo into a Dory memo without leaving the keyboard.
- **Paste a link onto your words.** Select some text, paste a URL, and the selection
  becomes a link — no more fiddling with brackets.

## Technical notes
- Slash commands ride the same `@tiptap/suggestion` plumbing as @/# autocomplete
  (`startOfLine`, plain-DOM renderer); the typed `/query` range is deleted and the
  item runs a schema operation — the markdown round-trip is untouched, and the
  markdown-bridge fidelity suite stays the contract. `/dory` is a host-provided
  command (`extraSlashCommands` prop) since it flips MemoEditor state.
- Paste handling: a plain-text `https?://` paste over a non-empty selection calls
  `setLink` and swallows the event; pasting with no selection keeps TipTap's default
  autolink behavior. File pastes still win.
- Deliberately absent: `/table` — tables aren't in the WYSIWYG schema (StarterKit),
  and adding them is its own schema + serializer change with fidelity-contract work.
