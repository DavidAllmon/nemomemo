## What's new
- **Tougher locks on the reef.** Someone hammering the sign-in door with password
  guesses now gets told to catch their breath and come back in a minute — real
  members won't notice a thing.
- **Sneaky files can't play dress-up anymore.** Uploaded files that could act like
  tiny web pages (like SVGs) now download instead of opening in your browser, so a
  booby-trapped file can't do anything sneaky. Pictures in your memos look exactly
  the same as before.
- **New passwords need 8 characters.** Existing passwords keep working — this only
  applies when you create or change one. A few extra characters go a long way.
- **Quieter armor everywhere.** A bundle of behind-the-scenes protections — the kind
  you never see but always want — now wraps every page and download.

## Technical notes
- Fixed-window in-memory rate limiter (`middleware/rate-limit.ts`), CF-Connecting-IP
  aware, wired to `/auth/signin` (10/min/IP), `/auth/signup` (30/hr/IP), and cloud
  `/cloud/checkout` (10/min/IP); 429 `RESOURCE_EXHAUSTED` with `retry-after`.
  `apiError()` now accepts extra response headers.
- File serving (audit F1): `X-Content-Type-Options: nosniff` on all `/file` responses
  (thumbnails included); non-allowlisted types (anything not raster image / audio /
  video / pdf — notably svg+html) get `Content-Disposition: attachment` +
  `Content-Security-Policy: sandbox`. Subresource loads ignore disposition, so
  `<img>`-embedded SVGs still render.
- Session cookie sets `Secure` when the request arrived over https, directly or via
  `x-forwarded-proto` (audit F4). Plain-http LAN self-hosts unaffected.
- Set-if-absent security headers middleware in `app.ts` (nosniff, `X-Frame-Options:
  DENY`, `Referrer-Policy: strict-origin-when-cross-origin`), also applied to error
  responses via `onError` (audit F5).
- Signin compares against a per-process dummy bcrypt hash when the username doesn't
  exist — no timing oracle for username enumeration (audit F7).
- Password minimum raised 6→8 in all shared schemas (`passwordSchema`), the cloud
  claim form (`minlength="8"`), and web form hints; signin still accepts legacy
  shorter passwords (audit F8).
- `avatarUrl` restricted to `data:image/*` (≤2MB) or http(s) URLs (≤2048 chars)
  via `avatarUrlSchema` (audit F6).
- New `server/src/test/hardening.test.ts` (17 tests) + 2 cloud-billing tests; suite
  is now 79 tests.
- New `docs/claude/` AI-assistant context docs (MAP, DATA-MODEL, GOTCHAS, WORKFLOWS)
  and a CLAUDE.md pointer section — documentation only, no runtime impact.
