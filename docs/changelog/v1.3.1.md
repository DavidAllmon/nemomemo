## What's new
- **Commenting is easy to find now.** Every memo in the feed shows a Comment
  link — before, it only appeared after someone had already commented, which made
  starting the conversation a treasure hunt. Click it, say your piece, done. 🐡

## Technical notes
- `MemoCard` footer: the comments link no longer requires `commentCount > 0`;
  zero-comment memos render a "Comment" label linking to `/memos/:uid#comments`.
  Web-only change, no API or schema impact.
