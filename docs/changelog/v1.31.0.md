## What's new
- **Text your reef.** Your NemoMemo can now have a Telegram bot: message it and
  what you send becomes a memo — a thought, a photo, or a voice note, with
  `#tags` working just like they do in the app. No app to install, and you're
  already signed in to Telegram on your phone.
- **Connect in two taps.** **Settings → Access → Connect Telegram** gives you a
  code; send it to the bot and that chat is yours. Disconnect any time, from
  either side.
- **Photos and voice notes come in whole.** A photo you send gets read by image
  search the same way an upload does, and a voice note gets transcribed — so
  the whiteboard you snapped on the way out is findable later.
- Reef keepers: this is off until you set a bot token. See
  [Deploy → Capture from Telegram](https://trynemomemo.com/docs/deploy). Note
  that messages to a bot pass through Telegram's servers and aren't
  end-to-end encrypted.

## Technical notes
- Migration 0011 adds `telegram_chat` (one member per chat) and
  `telegram_link_code` (single-use, 15 minutes, deleted on use). `chat_id` is
  TEXT because Telegram ids are int64.
- `services/telegram.ts` splits into `handleTelegramMessage()` — the whole
  decision tree, testable with no network — and `startTelegramBot()`, the
  getUpdates loop. The update offset persists in `instance_setting`, so a
  restart can't replay messages into duplicate memos.
- **The bot starts only from the single-tenant branch of `index.ts`.** In cloud
  mode one process serves every reef, and several pollers sharing one bot token
  would fight over Telegram's update queue; keeping the call site on that
  branch makes the bad configuration unreachable rather than merely discouraged.
- Ride-along: `storeAttachment()` extracted from the upload route into
  `services/attachment-service.ts` and shared with the bot, so Telegram media
  gets the same quota checks, disk layout, and OCR/transcription hand-off as a
  browser upload.
- Linking is session-only (`requireSessionViewer`) like token management —
  an access token can't point a reef at a chat. 16 new tests.
