## What's new
- **The comment box grew up.** It's now the same smart editor you write memos
  with: type `@` and your reef-mates' names pop up, type `#` for your tags,
  markdown works, and Cmd+Enter sends. No more guessing at usernames.
- **Conversations keep everyone in the loop.** When someone replies to a memo
  you've commented on, you'll hear about it in your inbox — not just the memo's
  owner. Threads feel like conversations now, not messages in bottles.
- **A friendly heads-up about private mentions.** If you @mention someone on a
  private memo, the comment box now tells you they won't be notified — private
  means private, even from pings. 🤫

## Technical notes
- `CommentEditor` (web): CodeMirror composer for comments sharing the memo
  editor's completion source (extracted to `editor/completions.ts` as
  `useMemberTagCompletions`); Mod-Enter submits; hint when parent is PRIVATE and
  the draft contains a mention.
- New inbox type `MEMO_THREAD` + `notifyThreadParticipants` in
  `services/inbox-service.ts`: distinct earlier commenters, excluding the reply
  author, the parent owner (gets MEMO_COMMENT), @mentioned users (get
  MEMO_MENTION), archived users; PRIVATE parents notify nobody.
- Migration `0002_inbox_thread_type.sql` rebuilds `inbox` to extend the type
  CHECK (SQLite can't alter CHECKs); rehearsed against a seeded pre-0002 DB —
  rows/ids/statuses preserved, `PRAGMA foreign_key_check` clean.
- `InboxDto.type` union + web inbox copy/icon extended; suite now 83 tests.
