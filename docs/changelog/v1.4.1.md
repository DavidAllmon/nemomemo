## What's new
- **Reply to anyone with one click.** Every comment now has a Reply button that
  starts your comment with their @name — so they get pinged and everyone can
  follow who's talking to whom.
- **Notifications drop you right into the conversation.** Clicking "so-and-so
  commented" now opens the whole thread with that comment highlighted — no more
  landing on a lonely comment floating in open water.
- **Editing a comment is just editing the words.** The visibility and Dory
  buttons are gone from comment editing — comments always follow their memo, so
  those switches never did anything there.
- **Visitors know how to join in.** Reading a public memo while signed out? The
  comments now end with a friendly "Sign in to join the conversation." 🐟

## Technical notes
- `MemoCard` gains an optional `onReply` prop (rendered only on comment cards in
  the detail view); `CommentEditor` accepts a `prefill` {text, nonce} that
  appends and focuses — Reply passes `@username `.
- `MemoDetailPage` redirects comment uids to
  `/memos/:parentUid#comment-:uid` (replace navigation); a `#comment-*` hash
  scrolls the target into view and applies a 2.5s ring highlight once comments
  load.
- `MemoEditor` derives `isComment` from `memo.parentUid`, hides the
  visibility/Dory controls, and omits those fields from the PATCH for comments.
- Web-only release; no API or schema changes.
