## What's new
- **What you type is what you see.** The memo editor is now a true rich-text
  editor: type `**bold**` and it turns bold instantly, `# ` starts a real
  heading, `[ ] ` makes a clickable checkbox — no more staring at raw markdown
  symbols. The toolbar works as before, and everything you've already written
  opens perfectly.
- **Comments got the same upgrade.** The comment box is the same smooth editor
  with a compact toolbar — @names and #tags still pop up suggestions as you
  type.
- **Your old habits still work.** If you like typing markdown, keep typing it —
  it just becomes real formatting the moment you finish. And behind the scenes
  your memos are stored exactly as before, so nothing about sharing, searching,
  or exporting changes.

## Technical notes
- Editors (composer, edit-in-place, comments) replaced CodeMirror with TipTap
  v3 + the official `@tiptap/markdown` extension; markdown remains the storage
  format — zero server/schema/shared changes; MemoContent rendering untouched.
- `web/src/lib/markdown-bridge.ts` is the single parse/serialize path;
  `markdown-bridge.test.ts` (the web package's first vitest suite, 27 tests,
  jsdom) pins byte-stable round trips, extraction equivalence against
  `extractProps`, and idempotence. Run it after any TipTap upgrade.
- `RichEditor.tsx`: full/slim toolbar variants, plain-text @/# suggestion
  popups (`@tiptap/suggestion`, no custom nodes), Mod-Enter submit, paste/drop
  upload hooks; drafts still autosave to localStorage as markdown.
- Edit saves compare serialized output against the loaded markdown and omit
  `content` when identical — no phantom "edited" badges from normalization.
- Known quirk: typing `- [ ] ` converts to a bullet at `- `; use `[ ] ` at line
  start or the checklist button. CodeMirror deps removed (~5 packages).
- Ops (VM, not in image): update.sh hardened after the 2026-08-22 disk-full
  deploy wedge — see docs/CLOUD-OPS.md.
