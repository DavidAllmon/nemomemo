## What's new
- **Put a face on your fish.** Settings → My account now has an avatar picker —
  choose any photo and it's shrunk down and shown everywhere your name appears.
- **Profiles worth visiting.** Profile pages grew up: a bigger avatar, when you
  joined the reef, how many memos you've written, your task and link tallies,
  your most-used tags (click one to filter the feed), and your writing-activity
  calendar.

## Technical notes
- Avatar: client-side canvas cover-crop to 256px webp data URI
  (`web/src/lib/avatar.ts`), stored via the existing PATCH `/users/-/account`
  and validated by `avatarUrlSchema` (v1.3.0). No server changes.
- Profile: renders existing `/users/:username/stats` data (tag counts, task/
  link/pinned counts, heatmap timestamps via the reusable `CalendarHeatmap`);
  tag chips call `toggleChip({type:'tagSearch'})` — profile paths were already
  filter-aware. Web-only release.
