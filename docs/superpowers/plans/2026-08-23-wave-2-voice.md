# Voice Memos + Transcription Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record a voice memo straight from the editor (audio attachment), play it inline, and — when `NEMOMEMO_TRANSCRIBE_URL` is set — transcribe it into `attachment.extracted_text` so search finds it and the transcript shows under the player. Own release: **v1.20.0**.

**Architecture:** The OCR release (v1.19.0) built the whole back half: `extracted_text`, `attachment_fts` triggers, the process-wide serialized job queue, and search OR-compilation. Transcription is just a second `OcrEngine` implementation (`transcribeEngine`) that POSTs the audio file to any OpenAI-compatible `/audio/transcriptions` endpoint; a second `OcrQueue` instance shares the same module-level lane. Web adds a Mic record button (MediaRecorder) to the editor toolbar, an inline `<audio>` player in `AttachmentPanel`, and a quiet transcript block fed by a new `AttachmentDto.extractedText` field.

**Spec:** `docs/ROADMAP.md` § Wave 2 (voice rows) + handoff memory. Config: `NEMOMEMO_TRANSCRIBE_URL` (full endpoint URL), `NEMOMEMO_TRANSCRIBE_KEY` (optional — local whisper.cpp needs none), `NEMOMEMO_TRANSCRIBE_MODEL` (default `whisper-1`). Cloud sets these fleet-wide via env — zero cloud code (ship-dark by construction).

## Global Constraints

- Green only; release v1.20.0 minor; both changelog sections; `--follow-tags`.
- **Public-docs-rule**: deploy.mdx gains the three `NEMOMEMO_TRANSCRIBE_*` rows + a section, same release.
- No real network calls in tests (fake engines / undici-free: the engine interface is injected exactly like OCR).
- `AttachmentDto.extractedText` is additive; it flows only through `buildMemoDtos`/attachment routes already gated by memo visibility (an attachment can never out-scope its memo).
- Transcript failures never fail an upload (same queue error-swallow).
- Reef voice for UI copy ("Record a wave", transcript label).
- MediaRecorder mimeType: probe `MediaRecorder.isTypeSupported('audio/webm')` else `audio/mp4` (Safari); filename `voice-memo-<ISO-ish stamp>.<ext>`.

- `services/transcribe.ts`: `transcribeEngine(url, key, model): OcrEngine` — reads the file, POSTs multipart (`file`, `model`) with optional `Authorization: Bearer`, returns `json.text ?? ''`; non-2xx throws (queue catches).
- config: `transcribe: { url; key: string | null; model } | null` via env; helpers force `transcribe: null` default in tests.

- Tests (`transcribe.test.ts`): fake engine → audio upload stores transcript + FTS hit through memo search; failure → upload fine; default → no queue.
