## Adding files

Paste a screenshot, drag files onto the editor, or use the image button in the toolbar.
Files attach to the memo when you save; images render inline with thumbnails and a
click-to-zoom viewer.

Uploads are capped at 32 MiB each and stored on the server's disk under your data
directory — no third-party storage involved.

## The library

**Attachments** in the sidebar lists everything you've uploaded, filterable by type
(media, audio, documents). Each file shows which memo owns it.

## Unused uploads

Files whose memo was deleted — or that never got attached — are marked **Not linked**.
The **Delete unused** button clears them all at once to reclaim space. Access to a file
always mirrors its memo: if someone can't see the memo, they can't fetch its attachments.
