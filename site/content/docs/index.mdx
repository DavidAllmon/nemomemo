Welcome to the reef. NemoMemo is a cute, self-hosted memo timeline: Markdown-native quick
notes with tags, filters, sharing — and Dory memos that forget themselves in 24 hours.

## Start here

- **[Getting started](/docs/getting-started)** — first run, first account, first memo.
- **[Deploy](/docs/deploy)** — Docker in one command, or build from source.
