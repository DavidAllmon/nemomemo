## Writing

The editor speaks GitHub-flavored Markdown: headings, **bold**, *italic*, ~~strikethrough~~,
lists, task lists, fenced code blocks with syntax highlighting, tables, images, and links.
The toolbar splices Markdown at your cursor; **⌘+Enter** saves. Drafts persist in your
browser, so a closed tab never eats a thought.

Interactive checkboxes work in the rendered memo too — tick `- [ ]` items right in the
timeline and the source updates itself. The **Tasks** submenu on a memo can check or
uncheck everything at once.

## Visibility

Each memo carries one of three levels, chosen in the editor:

| Level | Who can read it |
| --- | --- |
| Private | Only you |
| Protected | Any signed-in member of your instance |
| Public | Everyone, when the instance is in public mode |

Set your default in **Settings → Preferences**.

## Pinning

**Pin to top** keeps a memo above the timeline. Pinned memos can't be Dory memos —
pinned means forever, Dory means a day.

## Archiving

**Archive** moves a memo to the treasure chest: out of the timeline, safe forever,
restorable any time. Archiving a Dory memo rescues it from being forgotten.

## Deleting

Delete is permanent and takes comments, attachments, and share links with it. The app
asks first.
