title: Tags
description: Inline hashtags, nested hierarchies, renaming, merging, and colors.
---

Tags are extracted from your writing — nothing to file, nothing to create first.
Type `#reading` anywhere in a memo and the tag exists. When your reef grows, the
garden tools live in **Settings → Tags**.

## Nesting

Use `/` to build hierarchies: `#dev/docker` counts for both `dev` and `dev/docker`, so
filtering by the parent finds every child. The sidebar shows tags as a flat list or a
collapsible tree — toggle with the icons next to the TAGS header.

## Filtering

Click any tag — in a memo or in the sidebar — to filter your timeline to it. The filter
lives in the URL, so the view is bookmarkable.

## Pinning

Hover a tag in the sidebar and a star appears — click it and the tag joins a **Pinned**
section at the top, above the full list. Up to 20, in the order you pin them. Pinning is
per member, and a pinned tag quietly steps aside if its last memo goes away.

## Renaming & merging

**Settings → Tags** lists every tag you use. Renaming rewrites the tag across every
memo you own, including descendants (`old` → `new` also rewrites `old/idea`); code
blocks are left untouched. Rename onto a tag that already exists and NemoMemo offers
to **merge** them instead — every memo from the old tag pours into the new one.

Either way, each rewritten memo keeps its previous words in **⋯ → History**, so a
rename is never a leap of faith. A renamed tag's color and sidebar pin follow it to
the new name (when merging, the target tag's own color wins).

## Colors

Each tag row in **Settings → Tags** carries a palette of eight reef colors — pick one
and that tag's chips and sidebar `#` wear it everywhere. Colors are per member: you
see your palette, your reef-mates see theirs.

## What counts as a tag

Letters, numbers, and underscores, with `-` allowed inside segments. Tags inside links
and code are ignored.
